# Core 1.8.5 Benchmark-Derived Hardening

Core 1.8.5 is derived only from repeated Holdout-5 failure classes. It does not claim Stable-2.0 qualification from Holdout 5, which is now regression-only evidence.

## Fixed-Document Depth
<!-- id: benchmark-findings-1-8-5.fixed-document -->
Holdout 5 showed fixed documents could cover the requested topics while emitting too few distinct findings/conclusions and implications/actions. Core 1.8.5 therefore raises family-native depth and requires direct reader-facing takeaways plus stronger provenance density.

## Composite Continuity
<!-- id: benchmark-findings-1-8-5.composite-continuity -->
Correctly routed composites may still be adjacent files rather than one project. Core 1.8.5 requires shared assumptions/identifiers, visible cross-artifact handoffs, child acceptance references, and project-level provenance boundaries.

## Compact Containment
<!-- id: benchmark-findings-1-8-5.compact-containment -->
Responsive composite children now compile width-safe composition before freeze and must pass direct 320/390 no-overflow/no-clipping evidence independently.

## Dashboard / Workspace Boundary
<!-- id: benchmark-findings-1-8-5.dashboard-workspace -->
Decision-monitoring workspaces centered on renewal/status/risk/portfolio/compliance evidence resolve as Dashboard; authoring/task/case/workflow workspaces remain Web App / SaaS / Portal.

## Qualification Boundary
Any Stable-2.0 claim after this revision requires a new sealed Holdout 6. Holdout 5 may be used only for regression evidence.
